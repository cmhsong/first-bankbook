# 나의 첫 통장

예금과 적금을 배우고, 가상 통장을 만들어 만기까지 운영해 보는 웹 학습지입니다.

- 학습지 열기: https://cmhsong.github.io/first-bankbook/
- 은행 이름, 이자율, 계좌번호는 모두 연습용으로 꾸며 낸 것이며 실제 은행 상품과 다릅니다.

## 고치는 방법

`index.html`을 고친 뒤 `sh build.sh`를 실행하면 배포용 `docs/index.html`이 다시 만들어집니다.

## 사용한 오픈 소스

- [Day.js](https://github.com/iamkun/dayjs) (MIT)
- [canvas-confetti](https://github.com/catdad/canvas-confetti) (ISC)
- Noto Sans KR, Jua 글꼴 (OFL)
